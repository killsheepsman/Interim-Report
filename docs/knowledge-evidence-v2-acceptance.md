# 证据生成 V2 验收记录

## 范围

本次针对知识库证据生成增加了正文起点识别、封面/会签/修订记录/目录过滤、结构性表头过滤、标题片段合并和长文本按语义边界拆分。

- `吸嘴设计规范V1.0-20260123.docx`

## 规则变化

1. 正文从“目的”章节开始，封面字段、会签表、修订记录和目录不再作为证据。
2. “文件类型”“设计规范”“维护部门”“区域名称”等结构性标签不再单独成为证据。
3. 单独的数字、公式、单位、文件编号和引用文档不再成为证据。
4. “吸附区域选择”等章节标题会附着到后续完整陈述，不再单独展示。
5. 超过 900 字符的连续内容按句号、分号和列表等语义边界拆分，保留原文，不做固定长度截断。

## 使用要求

历史证据已写入数据库或 JSON 的文档不会自动重算。对已有文档点击“重新解析”，再重新蒸馏知识，才能让旧数据使用 V2 证据规则。
