# 真实问题匹配验收集

## 当前状态

验收脚本 `tests/knowledge-match-acceptance.mjs` 会从当前问题库按接线、吸嘴、气路、螺丝、BOM/图纸、端子/线束六类各抽取 5 条去重样本。样本只记录系统当前 Top1 结果，不把自动抽样当作标准答案。

运行：

```text
node tests/knowledge-match-acceptance.mjs
```

输出中的 `expectedKnowledgeIds`、`allowNoMatch` 和 `reviewStatus` 是人工确认字段。确认前 `reviewStatus` 为 `pending`，Top1/Top3 命中率保持为空，避免误报准确率。

## 页面确认位置

1. 进入“知识管理 → 知识库”。
2. 打开“问题与规范闭环”中的“问题匹配”。
3. 先选择“组装 / IPQC”或“研发 / DQA”，两类问题分开确认。
4. 在搜索框输入样本中的关键词，例如“接线”“吸嘴”“气路”“螺丝”“BOM”。
5. 选择问题后查看“匹配知识卡”结果。
6. 打开候选卡片，核对知识标题、知识来源、具体章节和原文依据。
7. 对每条样本确认：正确知识卡 ID；或者确认该问题允许无匹配。

每类先确认 5 条代表样本即可，不需要逐条处理 2 万条问题。确认结果用于后续计算 Top1、Top3、无匹配率和跨对象错误率。

## 当前自动抽样基线

当前使用 PostgreSQL 主数据源生成 30 条样本。现状基线为：

- 可取得 Top1 候选：4 / 30；
- 当前无候选率：86.7%；
- 潜在跨对象候选率：13.3%。

这不是最终准确率，因为标准答案尚未人工确认；它只用于定位“知识覆盖不足”和“候选对象错配”。
