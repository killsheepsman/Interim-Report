# 知识卡片匹配的升级待办

状态：暂缓。当前已先做三要素匹配，本项等确认后再开发。

## 要做的事

质量工程师不能只点确认/驳回。确认时要能写字，把「现场怎么说」改成「规范里怎么叫」，写入项目配对库。

未匹配上知识卡的问题，不让 AI 自动编补充。工程师在输入框里写措施，这条措施作为该问题的改善动作，写进对应人员的个人角色报告。

## 确认页要加的内容

有候选规范卡时：

1. 这其实是什么问题：对象、缺陷、过程，或一句话标准化。
2. 正确规范卡：搜索已发布卡片，或明确选「无匹配」。
3. 同类说法：销子敲进去了、销钉打过头。
4. 不要配到这些卡：例如气路调速阀。

没有候选规范卡时（例如「扎带未剪平」）：

5. 给一个措施输入框。工程师手写这条问题该怎么改、改到什么程度。
6. 保存后，措施跟这条问题、这个人绑定。
7. 生成个人角色报告时，把这些手写措施写进该人员本期报告，位置在改善措施，不进「已确认规范依据」，不生成考题。

点「校正后确认」后：

- 有正确卡的问题：按正确卡进入报告
- 黄金配对写入项目配对库，供以后同类问题使用
- 无匹配但写了措施的问题：措施进入该人员个人报告

## 配对库存什么

现场原话、标准化三要素、正确知识卡或无匹配、同类说法、反例、确认人、时间、模块。只收人工确认过的记录。

无匹配措施另存：问题、人员、措施原文、确认人、时间。不是规范卡，没有条款号。

## 匹配优先级

1. 现场原话几乎一样，直接用黄金配对
2. 对象+缺陷相同，用同一张卡
3. 现有三要素规则；对象对不上直接排除
4. 仍然配不上：保持无匹配，等工程师手写措施

配对库只提高匹配，不能自动确认进报告。AI 不自动给无匹配问题编常识、编风险、编条款。

## 明确不做

- 不微调大模型
- 不高分就自动当正确答案
- 不把题库只放在浏览器
- 错误确认可以改，改完旧配对作废
- 无匹配时不让 AI 自动补充内容
- 手写措施不当作 SOP，不出考试题

## 开发顺序

1. 确认页加文字框，配对库落表
2. 无匹配问题加措施输入框，措施写入个人角色报告
3. 匹配时先查黄金配对
4. 补跑邓海新这类 DQA 匹配
5. 再生成个人角色报告，核对：有卡的走规范依据，无卡有措施的走改善措施
