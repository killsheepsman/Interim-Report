# PM 项目质量闭环

质量数据由固定代码展示。分析结论和本月措施必须由模型写，数字只能用锁定结论，不能另造数字。

## 结论合同

1. 研发问题只写项数。没有送检分母，禁止写不良率。
2. 用当年 1 月到所选结束月，比较后一段和前一段。数量下降、数量上升、数量没有下降，三句只留对的那句。点出项数最高的月份。所选月高于上一个月时，写本月反弹。禁止「请继续保持」「还没到零」。
3. 约束分两列。研发问题看已分类和对应工程师。ECN 流量看物料行最多的工程师。措施先写流量，再写已经定位的图纸缺陷。
4. 分批下单不作为异常，不进异常 Pareto。可以单独写「不作为异常」。
5. 工程师物料行加总不等于表头时，写明两边数字和差额。不许静默。
6. 各 PM 比例只有分母相同才排名。对不上就写「分母不一致，本图不排名」。

## 数据边界

- 人名去掉工号。`刘洋(0104547(Disabled))` 和 `0104547(Disabled)(刘洋)` 都是刘洋。
- ECN 归属用第一列「PM审核人」。后面重复的同名列不覆盖。
- 加工件加总不等于表头时，和物料行一样写差额。
- 评审次数是所辖工程师到场，不写成 PM 本人到场。
- 分母为 0 的月份不能写成 0%。相邻月分母不同，要同时写出两个分母。


- 工程师名单只来自本期研发问题责任人、ECN 创建人、非 BOM 申请人，并且这一行的 PM 就是当前 PM。
- 研发问题以 PM 列为准。写成其他 PM 的问题归其他 PM。
- 研发问题表里阶段写成「评审」的行，不计入研发问题，也不计入评审次数或评审问题数量。评审次数和有效改善项只来自每一份评审表单。
- ECN 条数来自 ECN 汇总，一条 ECN 计一次。物料行来自查询导出，按行计次。两套数不能相加。
- ECN 比例 = ECN 条数 / 物料款数。加工件比例 = 本 PM 加工件物料行 / 全公司加工件总数。
- PM 不参加个人风险排名。

## 出具口吻

质量部发给本人。用「你 / 请你」。用「我们的目的是项目发布前把设计问题拦住。」不要复述锁定结论，不要照抄锁定措施表。分析要写清本月反弹落在哪个人的哪个现象，以及评审到场却没有改善项、所以没有拦住。
验收列必须写这一行 Owner 自己的现象原词，并要求该现象已关闭，同时出示改后图纸。禁止把别人的现象写进这一行。禁止只写分类名、「出示图纸」或「列出设计错误项数」。禁止「少于本期 N 项」。

## 验收打回
以下规则对所有模型相同。某次生成不通过，只重写该份报告，不再往这里追加。
- 分析必须写数量下降、数量上升或数量没有下降，并写尖峰月份。
- 分析必须写分母变化、加工件比例、非BOM加工件比例。没有分母的月份不能记成0%。
- 分批下单必须写明不作为异常。
- 分析结论和措施表都必须写物料行最多的工程师。
- 验收列只能关闭该行 Owner 自己的现象原词，不能把别人的问题写进这一行。
