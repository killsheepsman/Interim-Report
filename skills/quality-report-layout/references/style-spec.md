# 质量报告视觉规范

## 页面

- 画布：1440px 宽的网页预览；打印版使用 A4 纵向，左右边距 18mm。
- 主背景：`#F5F7FA`；卡片：`#FFFFFF`；边框：`#E5EAF0`；圆角：14px。
- 字体：中文优先 `Noto Sans SC, Microsoft YaHei, sans-serif`；数字优先 `Inter, Arial, sans-serif`。
- 正文 14px、行高 1.65；章节标题 20px；报告标题 30px；辅助信息 12px。

## 颜色

| 用途 | 颜色 | 文字建议 |
| --- | --- | --- |
| 高风险/严重 | `#D92D20` | 白色 |
| 中风险/注意 | `#F79009` | 白色 |
| 待核实 | `#FACC15` | `#3A2F00` |
| 深圳 | `#38BDF8` | `#075985` |
| 杭州 | `#8B5CF6` | `#4C1D95` |
| 通过/改善 | `#12B76A` | 白色 |
| 普通数据条 | `#3B82F6` | 白色 |

红/橙/黄是风险等级，不是字体颜色。正文和普通表格文字保持黑色；只有当事人标记、风险标签和必要的数值强调使用强调色。

## 章节顺序

1. 标题、统计周期、数据可信度
2. 关键指标卡片
3. 重点风险与二八集中度
4. 排名图表（替代重复排名表）
5. 结果—过程—根因—责任—行动
6. 30/60/90 天行动台账
7. 数据限制、验证计划和发布门禁

管理者报告将下级问题聚合到管理范围；个人报告保留当事人的具体问题。管理者本身不参与排名时，不绘制其个人排名。
