# IQC 来料质量分析

先执行 `quality-analysis-core`，再应用本模块规则。

## 数据与口径

至少核查来料批次、检验批次、不良批次或不良数量、批次良率、供应商、基地/厂区、物料/缺陷类型、日期和整改状态。

- 批次良率必须说明分子、分母及是否按批次计算。
- 不良批次、不良数量、问题记录数必须分开。
- 来料工作量增加不能直接解释为供应商质量恶化。
- 来料不良不能直接等同于制程损失、停线损失或客户损失。

缺少批次分母、供应商名称或日期覆盖时，将相应结论降为 C 级或待核实。

## 组织主线

按现有字段和映射分析：

```text
公司 → 基地/厂区 → 供应商 → 采购/SQE责任对象（仅在有映射时）
```

供应商是外部责任单元，不得把同名物料、厂区或采购人员当作供应商。没有采购/SQE映射时只汇报到供应商和管理部门，不虚构个人责任。

## 双重 Pareto

- 组织 Pareto：基地/厂区、供应商、物料类别。
- 机制 Pareto：尺寸、外观、性能、材料、包装、文件或平台已归一化的缺陷类型。
- 交叉 Pareto：高暴露供应商×集中缺陷类型。

供应商排序同时看检验批次、不良批次/数量、批次良率、重复问题、严重度和整改状态。样本量不足时不作强排名。

## 风险与机制

重点识别：重复来料缺陷、同一供应商多物料扩散、关键物料风险、检验后仍向制程逃逸、临时放行反复发生、整改无验证证据。

从规格与验收标准、供应商过程控制、来料抽样与测量、变更通知、异常隔离、采购/SQE接口和整改验证分析机制。不得仅用“供应商管理差”代替根因。

## 行动与输出

- 0—30天：隔离高风险批次，锁定TOP供应商和缺陷，补齐临时检验与放行证据。
- 31—60天：推动供应商纠正、过程审核、规格澄清、变更通知和来料防错。
- 61—90天：验证同类缺陷、批次良率和逃逸风险，关闭无效措施并横向展开。

正式报告突出供应商改善闭环、内部接收门禁和需要采购/SQE/管理层决策的事项。
