# Report Web Publisher

本 Skill 只管理报告的网页呈现，不参与质量结论、数字计算、根因判断或行动决策。

## 使用方式

- 页面从 `profiles/*.json` 读取可用 Profile，自动形成“网页呈现风格”下拉框。
- 新增经授权参考网页的风格时，只新增一个 Profile JSON（和可选说明文档），不修改质量分析 Skill。
- Profile 只能定义视觉层级、色彩 Token、图表位置、表格替换规则和响应式行为；不得复制第三方 Logo、文案、图片或品牌识别。
- 视觉渲染器读取 `REPORT_VISUAL_SPEC_JSON`。该数据块属于机器元数据，不得在最终网页正文中直接显示。风险文字仅对风险标签、标题和关键事实着色，正文保持黑色。

## 图表规则

- 对比、趋势、Pareto、排名、分布优先使用图表。
- 组织 × 机制、客户 × 主题、供应商 × 缺陷等双维交叉优先使用热力图。
- 构成变化优先使用堆叠柱形图；总量变化拆解优先使用瀑布图；关闭时长和机台量区间优先使用分布图。
- 暴露量、异常密度、严重度三者同时存在时优先使用散点图或气泡图。
- `tablePolicy: replace` 时，用同源图表替换统计表；责任、行动、证据、期限和关闭条件保留表格。
- 图表必须嵌入其来源章节，而不是集中放在报告顶部。
