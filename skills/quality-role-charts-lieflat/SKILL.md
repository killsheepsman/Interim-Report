# 角色报告图表 · Lieflat

用于个人角色报告的图表生成。只负责把固定 visualSpec 画出来，不改数字。

## 出图规则

- 柱顶或折线最高点距图上边缘 20 像素，画布高度跟数据走。
- 个人风险排名：横坐标文字横向排列。
- ECN 变更原因 Pareto：横坐标横向，长句按 / 、， 换行，不竖排。
- 后面有空位时把柱距拉开。
- 周趋势分子分母都为 0 的点不画。

## 适用图

问题分类、周/月趋势、ECN 原因、非BOM 构成、评审贡献、个人风险排名。
